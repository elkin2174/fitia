# Bodega y Semillas (Seeds)

Archivos versionados en formato JSON/YAML para alimentar la base de datos (ADR-06):
- `academic_programs.json`: Listado de programas de la Universidad del Valle.
- `exercises.json`: Catálogo de ejercicios curados.
- `routines.json`: Rutinas parametrizadas por tiempo y disponibilidad de máquinas.
- `exercise_guides.json`: 15 guías paso a paso de técnica de ejercicio.
- `holidays.json`: Festivos de Colombia y calendario académico de Univalle.
- `static_challenges.json`: Retos estáticos predefinidos para fallback de IA.
